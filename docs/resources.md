# External resources log

No external resources (web pages, repositories, papers, search engines) were consulted at any point during the run.
Everything was implemented from the model's own prior knowledge, including:
- chess-programming techniques (bitboards/PEXT attack tables, PVS, TT, null move, LMR, SEE, history heuristics, NNUE architecture and training);
- PeSTO-style piece-square tables, recalled from memory (they only seeded the initial hand-crafted eval, which was later replaced by the NNUE net).
The only data used were the files supplied in resources/ (fastchess, Stash engines as opponents, UHO.pgn opening book for tests and for some self-play training openings, perft.epd, UCI protocol) and data/nets generated by the engine itself during this session.
